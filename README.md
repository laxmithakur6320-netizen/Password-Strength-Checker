# Password Strength Checker 🔐

A beginner-friendly Python project that checks password strength based on length, uppercase letters, lowercase letters, numbers, and special characters.

## Features
- Checks for uppercase and lowercase letters.
- Detects numbers and special characters.
- Validates password length (minimum 8 characters).
- Classifies password strength as Weak, Medium, or Strong.

## Technologies Used
- Python 3
- Conditional Statements
- Loops and String Methods

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

`python main.py`

## Learning Purpose
This project was created to practice Python fundamentals, including strings, built-in functions, Boolean values, and conditional statements.

**Note:** This is a basic educational tool and does not provide a complete assessment of password security.
